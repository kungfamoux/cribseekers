# CribSeekers Design System
## Phase 6: Low Fidelity Wireframes

**Version:** 1.0.0  
**Date:** July 20, 2026  
**Status:** Draft  
**Designer:** Head of Product Design

---

# Executive Summary

This document defines low-fidelity wireframes for all key pages in the CribSeekers platform. Wireframes establish structural layout, component placement, information hierarchy, and user flow mapping without visual styling.

**Total Wireframes:** 45  
**MVP Pages:** 12  
**Wireframe Format:** ASCII-based structural diagrams  
**Focus:** Layout, hierarchy, component placement

---

# Wireframe Legend

```
┌─────────────────────────┐  = Container/Card
│ [Text]                 │  = Text content
│ [Button]               │  = Interactive element
│ [Input]                │  = Form input
│ [Image]                │  = Image/media
│ [Icon]                 │  = Icon
│ ─────────────────────  │  = Divider
│ •                      │  = List item
│ □                     │  = Checkbox
│ ○                     │  = Radio
│ ◉                     │  = Selected radio
│ ☑                     │  = Checked checkbox
```

# 3. Wireframe Summary

## MVP Pages Wireframed

1. **Landing Page** - Hero, search, trust strip, featured properties, AI section
2. **Login** - Email/password form, social login options
3. **Sign Up** - Registration form with validation
4. **Home Dashboard** - Welcome, quick actions, AI recommendations, featured properties
5. **Property Search** - Filter sidebar, results grid, pagination
6. **Property Details** - Gallery, info, tabs, description, amenities, location
7. **Book Inspection** - Property summary, calendar, time slots, notes
8. **Messages** - Conversation list, chat window, typing indicator
9. **Wallet** - Balance card, quick actions, transactions, linked cards
10. **Profile** - Profile header, details, statistics, settings links

## Layout Patterns

### Desktop (1280px+)
- 12-column grid
- Sidebar for filters/navigation
- Maximum width containers
- Horizontal scrolling for galleries

### Tablet (768px-1023px)
- 8-column grid
- Condensed sidebars
- Stacked layouts
- Touch-optimized

### Mobile (320px-767px)
- Single column
- Bottom navigation
- Horizontal scroll for lists
- Modal drawers for filters

## Component Placement

### Navigation
- Top: Logo, primary nav, user menu
- Mobile: Hamburger menu, bottom tabs

### Content
- Hero: Full width, prominent
- Cards: Grid layout, responsive
- Forms: Centered, max width

### Actions
- Primary: Right-aligned or centered
- Secondary: Inline or dropdown
- Sticky: Bottom or top
